# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who takes part in issues, pull requests, discussions or any other
project space is expected to follow it.

## Reporting

Report unacceptable behaviour to the maintainer at **aurimas.nausedas@proton.me**. Every report is
reviewed and handled in confidence.

## Enforcement

The maintainer applies the
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
of the Contributor Covenant 2.1: correction, warning, temporary ban and permanent ban, depending on the
impact of the behaviour.
